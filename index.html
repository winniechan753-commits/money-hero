Core Features

一個真正可以落地嘅 MVP

第一版先集中做最重要、最容易俾家長同小朋友測試嘅功能。

🐷

四個錢罌

Spend / Save / Share / Grow，建立分配零用錢習慣。

🎯

儲蓄目標

用單車、LEGO 等具體目標學延遲滿足與計劃。

📚

短課 + Quiz

3–5 分鐘情境學習，完成後得到 XP 同徽章。

🌱

模擬投資

只用虛擬資金，認識現金、債券、ETF、股票與風險。

6–12 Curriculum

由認識金錢，到投資入門

課程按年齡同理解能力逐步解鎖，避免太早將「投資」變成炒賣遊戲。

6–7 · Money Explorer港幣、價格、需要 vs 想要
7–8 · Saving Hero儲蓄、目標、耐性
8–9 · Budget Hero收入、預算、使 / 儲 / 分享
9–10 · Banking Hero銀行、利息、電子支付
10–11 · Growth Hero複利、通脹、風險
11–12 · Investment Hero股票、ETF、債券、分散投資
